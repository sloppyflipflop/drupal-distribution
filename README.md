# Drupal Distribution

A Drupal development project for exploring, extending, and evaluating Arizona State University's Webspark platform.

## Goals

- Build on ASU's official Webspark distribution and components.
- Explore Drupal architecture, configuration, and site-building workflows.
- Develop accessibility and usability improvements.
- Evaluate performance and maintainability.
- Create custom functionality without modifying upstream ASU modules.

## Development environment

- Drupal and ASU Webspark
- DDEV
- Composer
- Git
